# NBA Draft Duel

手机优先的双人 NBA 历史球员随机选秀网页游戏。

## 玩法
- 两台手机打开同一个网址
- 手机 A 创建 4 位房间码
- 手机 B 输入房间码加入
- 双方交替随机抽 NBA 球队
- 中文/英文搜索历史球员
- 同一真人球员整局不可重复
- 填满 PG/SG/SF/PF/C 后由房主开始比赛模拟
- 70% 阵容/对位 + 30% 单场随机波动

## 启动
```bash
npm install
npm start
```

## 公网部署
支持 WebSocket 的 Node.js 托管平台即可。
已附带 `Dockerfile` 和 `render.yaml`。
